# Glaze test & recipe log: draft

**Status:** draft for review. Not for sale and not customer-ready. Nothing is listed or launched.

**Provenance:** built by an AI tool (Claude). Formulas were checked by recalculating in LibreOffice only, and no domain user has reviewed them yet. Leaving the Instructions sheet blank avoids false content, but it is not evidence of human authorship. Source citations below are leads to re-check at the named source, not established facts.

## What it is
An Excel workbook (it also opens in Google Sheets) for potters testing glazes. It has three working sheets:
- **Ingredients:** materials with price per lb.
- **Batch Calculator:** scales any recipe to a batch size in grams. It normalizes the percentages to 100%, shows grams of each material, and works out batch cost.
- **Test Log:** up to 1,000 test tiles, with dropdowns for atmosphere, application, thickness, a 1-to-5 result and keep/retest. It also counts tiles logged and keepers.

## Important: no recipes are included
The percentages in the Batch Calculator are **placeholders to show the math, not a tested glaze**. Etsy's Oct 22, 2026 policy bans AI-generated recipes, and an untested recipe could also mislead buyers. Any recipe content in a listed product must come from Cash or be removed.

## Verified
All formulas were recalculated in LibreOffice. A 1,000 g batch at 40/25/20/10/5 gives 400, 250, 200, 100 and 50 g. The total checks at 100%, and the batch cost works out to $2.28 using the example prices.

## Checked against a published method

Source: Ceramic Arts Network, "Advice for Keeping a Kiln Log" (https://ceramicartsnetwork.org/daily/article/Advice-for-Keeping-A-Kiln-Log).

| Their recommendation | This template |
|---|---|
| Date, cone, atmosphere | Test Log |
| Firing program / schedule | Test Log column L (added) |
| Peak temperature and holds | Test Log column M (added) |
| Slow cool | Test Log column N (added) |
| Load position | Test Log column O (added) |
| How each glaze layer was applied | Test Log column P "Layers (order, coats)" plus application and thickness (added) |
| Results notes | Result 1–5, Keep?, notes/photo file |
| Firing count per kiln / elements | Not included: this is a test-tile log, not a full kiln log. Gap noted for Cash to decide. |

Verified by recalculating in LibreOffice: tile counts now sit in S1/S2 and read correctly.
